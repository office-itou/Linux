# kexec options

* SYNOPSIS

  ``` bash
  /sbin/kexec [-v (--version)] [-f (--force)] [-x (--no-ifdown)] [-y (--no-sync)] [-l (--load)] [-p (--load-panic)] [-u (--unload)] [-e (--exec)] [-t (--type)] [--mem-min=addr] [--mem-max=addr]
  ```

* <details><summary>OPTIONS</summary>

  |         オプション        | 説明                                                                                                                                                                                                                                                                                    |
  | :------------------------ | :-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
  | -d (--debug)              | デバッグメッセージを有効にする。                                                                                                                                                                                                                                                        |
  | -S (--status)             | 指定されたタイプ（デフォルトでは crash）がロードされている場合は 1、ロードされていない場合は 0 を返します。-l または -p オプションと組み合わせて使用​​することで、タイプの切り替えが可能です。このオプションは他のオプションよりも優先され、カーネルのロードやアンロードは行われません。  |
  | -e (--exec)               | 現在ロードされているカーネルを実行します。シャットダウン(8)を呼び出さずに、ロードされているカーネルで再起動することに注意してください。                                                                                                                                                 |
  | -f (--force)              | kexec を即座に呼び出し、shutdown(8) は呼び出しません（オプション パラメータを指定しない場合のデフォルトの動作とは異なります）。このオプションは、-l と -e を 1 つの呼び出しで実行するのと同じ動作を実行します。                                                                         |
  | -h (--help)               | kexecのヘルプファイルを開いてください。                                                                                                                                                                                                                                                 |
  | --hotplug                 | カーネルがCPU/メモリのホットアド/リムーブイベント時にkexecセグメントを安全に更新できるように設定します。このオプションを有効にすると、カーネルはCPU/メモリのホットアド/リムーブイベント時にkexecセグメントをカーネル内で更新するため、kdumpカーネルを再ロードする必要がなくなります。   |
  | -i (--no-checks)          | 高速再起動、メモリ整合性チェックなし。                                                                                                                                                                                                                                                  |
  | -l (--load) kernel        | 指定されたカーネルを現在のカーネルにロードします。                                                                                                                                                                                                                                      |
  | -p (--load-panic)         | パニック発生時に使用する新しいカーネルをロードします。                                                                                                                                                                                                                                  |
  | -t (--type=type)          | 新しいカーネルがこのタイプであることを指定してください。                                                                                                                                                                                                                                |
  | -s (--kexec-file-syscall) | 新しいKEXEC_FILE_LOADシステムコールを排他的に使用するように指定します。XENでは無視されます。                                                                                                                                                                                            |
  | -c (--kexec-syscall)      | 旧バージョンのKEXEC_LOADシステムコールのみを使用するように指定します。                                                                                                                                                                                                                  |
  | -a (--kexec-syscall-auto) | まず新しいKEXEC_FILE_LOADシステムコールを試してみて、それがサポートされていない場合、またはカーネルが提供されたイメージを理解できない場合は、古いKEXEC_LOADインターフェースにフォールバックします。                                                                                     |
  | -u (--unload)             | 現在のkexecターゲットカーネルをアンロードします。キャプチャカーネルをアンロードする場合は、-uオプションに加えて-pオプションを指定してください。                                                                                                                                         |
  | -v (--version)            | インストールされているユーティリティのバージョン番号を返します。                                                                                                                                                                                                                        |
  | -x (--no-ifdown)          | 実行中のカーネルをシャットダウンするが、再起動時にインターフェースを復元する。                                                                                                                                                                                                          |
  | -y (--no-sync)            | 実行中のカーネルをシャットダウンするが、ファイルシステムの同期はスキップする。                                                                                                                                                                                                          |
  | --mem-min=addr            | コードをロードするメモリの最小アドレス（addr）を指定してください。                                                                                                                                                                                                                      |
  | --mem-max=addr            | コードをロードするメモリの最高アドレス（addr）を指定してください。                                                                                                                                                                                                                      |
  | --entry=addr              | ジャンプバックアドレスを指定してください。（0はジャンプバックしない、またはコンテキストを保持することを意味します）                                                                                                                                                                     |
  | --load-preserve-context   | 新しいカーネルをロードし、kexec実行中に現在のカーネルのコンテキストを保持します。                                                                                                                                                                                                       |
  | --load-jump-back-helper   | ヘルパーイメージをロードして、元のカーネルに戻ります。                                                                                                                                                                                                                                  |
  | --reuseinitrd             | 初回起動時のinitrdを再利用します。                                                                                                                                                                                                                                                      |
  | --print-ckr-size          | クラッシュカーネル領域のサイズが利用可能な場合は、それを表示します。                                                                                                                                                                                                                    |

</details>

* <details><summary>SUPPORTED KERNEL FILE TYPES AND OPTIONS (bzImage-x86)</summary>

  |         オプション        | 説明                                                                                                                                                                        |
  | :------------------------ | :-------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
  | --append=string           | カーネルコマンドラインに文字列を追加します。                                                                                                                                |
  | --command-line=string     | カーネルコマンドラインを文字列に設定します。                                                                                                                                |
  | --reuse-cmdline           | 実行中のシステムからコマンドラインを使用してください。パニックカーネルがロードされると、crashkernel パラメータは自動的に削除されます。BOOT_IMAGE パラメータも削除されます。 |
  | --initrd=file             | ファイルをカーネルの初期ラムディスクとして使用します。                                                                                                                      |
  | --ramdisk=file            | ファイルをカーネルの初期ラムディスクとして使用します。                                                                                                                      |
  | --real-mode               | リアルモードのエントリポイントを使用してください。                                                                                                                          |

</details>

* <details><summary>ARCHITECTURE OPTIONS</summary>

  |         オプション        | 説明                                                                                                        |
  | :------------------------ | :---------------------------------------------------------------------------------------------------------- |
  | --console-serial          | シリアルコンソールを有効にします。                                                                          |
  | --console-vga             | VGAコンソールを有効にします。                                                                               |
  | --elf32-core-headers      | ELF32形式でコアヘッダーを準備します。                                                                       |
  | --elf64-core-headers      | ELF64形式でコアヘッダーを準備します。                                                                       |
  | --reset-vga               | 標準VGAデバイスのリセットを試みます。                                                                       |
  | --serial=port             | デバッグ出力用のシリアルポートを指定してください。                                                          |
  | --serial-baud=baud_rate   | シリアルポートのボーレートを指定してください。                                                              |
  | --dt-no-old-root          | フラット化デバイスツリーを作成する際に、古いカーネルの root=\<device\> パラメータを再利用しないでください。 |

</details>
